# 커스텀 두더지 잡기

캐릭터 이미지를 브라우저에서 등록해 두더지로 플레이하는 로컬 웹 게임입니다. 이미지 업로드는 서버로 전송하지 않고 브라우저 메모리에서만 처리합니다. 게임 종료 후 닉네임과 점수를 SQLite 온라인 랭킹에 등록할 수 있습니다.

## 게임 방법

1. 설정 화면에서 기본 PNG 두더지를 하나 이상 등록하고, 필요하면 맞았을 때 이미지와 폭탄 이미지를 등록합니다.
2. 게임 시작 후 두더지를 클릭하면 점수를 얻고, 연속 적중하면 콤보 보너스를 받습니다.
3. 두더지를 놓치면 반 하트, 폭탄을 누르면 하트 1개를 잃습니다. 하트가 0이 되면 게임 오버입니다.

## 랭킹 API

- GET /health - 서버 상태를 확인합니다.
- GET /api/rankings - 점수 상위 10개를 반환합니다.
- POST /api/scores - {"nickname": "닉네임", "score": 100} 형식으로 점수를 등록합니다.
  - 닉네임은 앞뒤 공백을 제거한 뒤 1~12자여야 합니다.
  - 점수는 0 이상 10,000,000 이하의 정수여야 합니다.
  - 같은 닉네임은 최고 점수 하나만 유지됩니다.

## 설치 방법

Python 3.11 이상을 설치한 PowerShell에서 프로젝트 폴더로 이동합니다.

~~~~powershell
py -3 -m pip install -r requirements.txt
~~~~

가상환경은 필수가 아닙니다.

## 실행 방법

~~~~powershell
py -3 -m uvicorn app:app --host 127.0.0.1 --port 8000
~~~~

브라우저에서 http://127.0.0.1:8000 을 엽니다.

## DB 경로 설정

기본 DB 파일은 실행 폴더의 scores.db입니다. PowerShell에서 환경 변수로 경로를 바꿀 수 있습니다.

~~~~powershell
$env:DUDOGI_DB_PATH = "C:\path\to\scores.db"
py -3 -m uvicorn app:app --host 127.0.0.1 --port 8000
~~~~
